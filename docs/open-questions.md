## 1. 阴刻槽顶做 45° 尖拱 + 刻字深度 1.2 → 0.6mm

**动机**：阴刻把图案挖进盖印面，槽顶是水平朝下的天花板，要跨过槽宽桥接。社区参数：悬垂 ≤45° 高质量、桥接 >15mm 必塌、**刻字深度建议 ≈ 一个喷嘴直径**（[Pollen AM · Overhangs](https://www.pollen.am/design_for_3d_printing_overhangs/) / [Bridges](https://www.pollen.am/design_for_3d_printing_bridges/) / [Engraving](https://www.pollen.am/design_for_3d_printing_engraving_details/)）。我们默认深度 1.2mm 是 0.4mm 喷嘴的 3 倍。

**做法**：槽在 z=0 的开口保持精确（这才是盖印面），往上按 45°（或 0.2mm 台阶）收口，让槽顶变成山墙而不是平顶。跨度 ≤ 2×深度 的槽能完全闭合。

**代价（小橙预判，未验证）**
- **两条深宽比规则会失效**：`groove.aspect` = 深度/槽宽，0.5mm 槽在 1.2mm 深时是 2.4（贴着 2.5 的上限），改 0.6mm 深后只有 1.2，基本永不触发；`relief.aspect` 同理。到时要么保留下限、要么降级为提示——否则就是两个不会响的守卫。
- **现有 2D 测量全部失效**：`prepareSection` 只处理平面图案，槽现在是直壁柱体；尖拱必须在挤出阶段做。而 `raster.ts` 量的是 2D 投影宽度，量不出「槽顶开口 vs 槽底宽度」的差别。要判尖拱的可打印性得换判据（开口宽度 ≳ 喷嘴直径，或直接量 3D 三角形）。
- 不受影响的：`ridge.min`（只看宽度）、`weld.ratio`（闭运算是纯 2D，5% 阈值仍有效）。

**要改的地方**：`src/geometry/pipeline.ts` 的挤出部分、`printability.ts` 的深宽比校准、新增 3D 判据。

## 2. 内置主体的总高上限

**现状**：只按底面足迹缩放到 `sizeMm`，高度随模型比例走。30mm 章面下：常见样式 30.5mm、石墩 29mm、圆柱 **64.5mm**、立方柱 **65.9mm**（源模型是瘦高型）。UI 会实时提示「章面尺寸 → 总高约 XX mm」。

**若要加总高上限**，缩放规则必须是**取小**而不是替换：

```ts
scale = min(sizeMm / 足迹, maxHeightMm / 源高)   // 谁紧谁说话
```

- 纯替换（`maxHeight / 源高`）会出事：圆柱压到 30mm 高时足迹只剩 **13.9mm**，刻不下四个字。
- 代价：`章面尺寸` 从「精确值」变成「上限」，面板上必须把这个语义说清，否则用户设了 30mm 却得到 20mm 会以为是 bug。

**要改的地方**：`pipeline.ts` 里缩放那一行（居中、z=0、朝向断言都不用动）、`App.tsx` 面板文案。

**状态**：用户 2026-11-13 未答，按「不加新控件、如实提示」处理，已写进 README 已知限制。
